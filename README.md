# igb-vgt-bundle

Machine-generated data for an Illinois video gaming terminal (VGT) companion app.

`bundle.json` holds establishment-level monthly video gaming revenue for about
the last 12 months: terminal count, amount played, net terminal income, and
hold %. It also includes licensed-establishment addresses and map coordinates.
It is regenerated and committed automatically once a month, so please don't
edit it by hand.

Raw file: https://raw.githubusercontent.com/phawk711/igb-vgt-bundle/main/bundle.json

## Source

- Revenue and licensee data are public records published by the
  [Illinois Gaming Board](https://igb.illinois.gov/).
- Coordinates come from the U.S. Census Bureau Geocoder.

Beyond formatting and geocoding, the data is republished as-is. For official
figures, go to the Illinois Gaming Board.
